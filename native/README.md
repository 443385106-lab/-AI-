# 匠心矢量设计 1.10 Native

自主开发的 Windows 原生矢量设计软件底座，兼容专业图文设计工作流程，但不包含 CorelDRAW 专有代码、界面素材或 CDR 文件解析规范。

## 当前可用能力

- Qt 6 / C++20 原生桌面界面，适配 Windows 10/11 64 位和高 DPI
- 专业设计工作区：菜单、属性栏、左侧工具箱、标尺、无限工作区、页面、右侧对象图层、状态栏
- 基础对象：矩形、椭圆、直线、自由手绘路径、美术字
- 贝塞尔钢笔：连续曲线绘制、开口/闭合路径、节点与控制点拖拽
- 六类布尔造型：焊接、修剪、相交、简化、前减后、后减前
- 对象操作：选择、多选、移动、尺寸、旋转、镜像、层级、组合、解组、页面/对象对齐与等距分布
- 图层：新建、改名、切换、显隐、锁定，对象按当前图层创建
- 图框精确裁剪：对象置于图框内部并可提取内容
- 文字排版：美术字、段落文本、字体/字号、粗体、斜体、左中右及两端对齐
- 文本框：宽高设置、溢出检测和自动缩字号
- 色彩填充：纯色、线性渐变、径向渐变、无填充、对象透明度
- 轮廓与色板：实线/虚线/点线/点划线，底部16色快捷填充
- 可编辑特效：多层轮廓图、矢量偏移阴影、两对象形状与颜色调和
- 封套预设：上窄下宽、上宽下窄、拱形、旗形，结果转换为可编辑曲线
- 位图工作流：PNG/JPG/BMP/TIFF导入、灰度、黑白阈值、提亮
- 离线基础描摹：把深色区域转换为可编辑矢量路径，适合标志、线稿和高对比图案
- SVG导入：保留矢量渲染，可随JXV工程保存、移动、缩放和再次导出
- 印前设置：0—20mm出血预览、可选裁切标记、300dpi含出血印刷PDF
- 印前预检：检查越界、透明度、字体、文字溢出和低分辨率位图
- 交付格式：新增95质量JPG和300dpi TIFF
- 批量导出：一次选择最多20个JXV工程，批量输出PDF、SVG、PNG、JPG或TIFF
- 智能制度展板：只输入制度名称即可生成标题、正文、边框、底色和落款版式
- 本地内容规则：自动匹配消防、食品卫生、仓库、岗位职责、设备规程、应急、质量等常见主题
- 六套行业版式：政务蓝、安全红、食品绿、车间橙、医疗蓝、简约金
- 专业成品尺寸：40×60、50×70、60×80、60×90、80×120厘米及常用横版
- 批量生成：一次输入最多20个名称，分别生成JXV、PDF，并可选择300dpi PNG
- 真实300dpi：位图像素按成品毫米尺寸计算，不再使用固定倍率
- 样图版式分析：提取角部底色、主色、辅色，估算标题区高度与边框内缩
- LOGO位置候选：分析样图左上区域，按结果生成可替换的LOGO占位对象
- 可编辑仿制：分析结果重建为独立的底色、边框、标题、正文和落款对象
- 本地模板库：六套内置模板，并支持将当前设计保存为自定义模板
- 模板管理：模板搜索、行业分类、收藏/取消收藏、应用和删除自定义模板
- Windows本地OCR：调用Windows 10/11系统文字识别，不需要联网或API密钥
- OCR内容提取：识别中文、英文和数字，自动提取标题、正文和逐行位置坐标
- OCR标准重排：校对识别文字后，自动生成标题栏、正文、边框、底色和落款
- OCR原位重建：按样图中的文字区域生成独立、可移动、可编辑的文字对象
- 样图智能联动：版式分析会自动尝试OCR并预填标题正文，识别失败仍可手工输入
- 大图预处理：超过2400像素自动等比缩放，支持取消和120秒超时保护
- 结构智能识别：根据OCR文字区域自动判断单栏、双栏或三栏版式
- 阅读顺序整理：多栏内容按从左到右、栏内从上到下重新排序，避免正文串栏
- 分栏矢量重建：按识别结果生成独立段落文本框、栏间线，并自动检测文字溢出缩字号
- 表格线检测：扫描样图中的长横线和长竖线，自动聚合重复像素线并判断表格结构
- 表格矢量重建：重画可编辑横竖线，按单元格范围放置独立文字对象
- 手动结构修正：识别后可覆盖为单栏、双栏或三栏，再生成适合设计师继续修改的版式
- 本机品牌资料：保存公司名称、SVG/位图LOGO、主色、辅色、LOGO位置和尺寸
- 一键品牌套用：自动替换落款与LOGO占位，并更新标题栏、内外边框和表格线颜色
- 批量品牌套版：一次选择最多20个JXV工程，输出独立的“品牌版”可编辑工程
- 全局文字替换：支持区分大小写，一次替换当前设计中的客户名称、部门或制度用语
- 安装更新保护：安装前自动结束旧程序进程，被安全软件占用时提供明确的重试指引
- 中文安装界面修复：GitHub构建时强制以UTF-8 BOM编译NSIS脚本，避免标题乱码
- 大段制度文字导入：支持粘贴或读取TXT，自动清理多余空行并生成可编辑段落文本框
- 文本框八点调整：拖动四边和四角改变宽高，Shift保持比例，Ctrl同步缩放文字
- 溢出可视提醒：选中文本框时以红色虚线显示溢出，正常状态显示蓝色控制框
- 文本自适应：一键缩字号适配或让文本框高度贴合内容
- 制度层级样式：自动识别标题、一级条款、二级细则和备注，分别设置字号、字重、颜色、行距与段距
- 多级条款编号：支持中文序号、数字序号、第N条及缩进子编号
- 全板格式统一：批量统一字体、正文颜色、字号、行距和段后距，并可保留标题强调样式
- 安全文字转曲：选中或全板转为真实字形路径，同时保存隐藏、锁定的可编辑文字备份
- 富文本工程保存：JXV第6版保存段落内不同字形与层级格式
- 辅助能力：网格、5单位智能吸附、框选、缩放、平移、方向键微移
- 自主工程格式：`.jxv` JSON文档，支持打开、保存、另存和50步历史记录
- 导出：SVG矢量图、PDF、300dpi PNG

## 暂未冒充完成的能力

以下模块已经预留菜单和架构位置，但不在当前基础版本中虚假宣称完成：

- 尖点/平滑/对称节点一键类型切换与控制柄联动
- 文字绕图、OpenType高级字形与跨页文本链
- 网状填充、自由网格封套、动态调和控制柄、模糊阴影
- ICC/CMYK/Pantone分色与专色色彩管理
- 多色AI位图描摹和PSD/AI/EPS导入
- 手写体OCR、合并单元格判断与无框复杂表格的高精度重建
- 原生CDR读写

CDR交付继续使用现有软件中的 CorelDRAW X7—2020 合法联动模块。

## 本地编译

安装 Qt 6.5+（Widgets、Svg、PrintSupport）、CMake 3.21+ 和 Ninja：

```powershell
cmake -S native -B native/build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build native/build
```

GitHub Actions 工作流 `.github/workflows/build-native-windows.yml` 会生成可安装 EXE 和免安装 ZIP。
